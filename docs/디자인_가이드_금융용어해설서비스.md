# 1. 디자인 철학 및 원칙

## 1.1 핵심 컨셉: '조용한 보조자'

본 서비스는 금융 약관을 읽는 사용자의 흐름을 방해하지 않는 것을 최우선 원칙으로 하며, 필요한 순간에만 최소한의 시각적 개입을 통해 이해를 돕는 **'조용한 보조자(Quiet Assistant)'** 역할을 지향합니다.

### 조용한 보조자의 의미

- **존재감의 최소화**: 사용자가 약관에 집중할 수 있도록 서비스 자체는 눈에 띄지 않게
- **필요한 순간의 명확함**: 사용자가 도움이 필요한 순간에만 명확하고 간결하게 정보 제공
- **신뢰할 수 있는 안정감**: 차분하고 전문적인 톤으로 금융 서비스의 신뢰성 전달
- **부드러운 배려**: 모든 인터랙션이 자연스럽고 부드럽게 느껴지도록

## 1.2 디자인 핵심 원칙

### 1. 비침해성 (Non-Intrusive)

**목표**: 사용자의 읽기 흐름을 절대 방해하지 않음

**구현 방법**:
- 하이라이트는 점선 밑줄 등 미세한 시각적 표시
- 팝업은 콘텐츠를 가리지 않는 위치에 배치
- 애니메이션은 부드럽고 빠르게
- 강렬한 색상이나 큰 움직임 금지

**Do's**:
- ✅ 점선 밑줄 (dashed underline)
- ✅ 연한 배경 색상
- ✅ 0.3초 딜레이 후 팝업 표시
- ✅ 부드러운 페이드 인/아웃

**Don'ts**:
- ❌ 깜빡이는 효과
- ❌ 형광색이나 강렬한 색상
- ❌ 갑작스러운 팝업
- ❌ 큰 영역을 차지하는 오버레이

---

### 2. 명료성 (Clarity)

**목표**: 필요한 정보만 명확하게 전달

**구현 방법**:
- 간결한 텍스트 (1-2문장)
- 명확한 시각적 계층 구조
- 충분한 여백
- 읽기 쉬운 폰트와 크기

**Do's**:
- ✅ 중학생 수준의 쉬운 언어
- ✅ 구체적인 숫자 예시
- ✅ 명확한 제목과 본문 구분
- ✅ 충분한 줄 간격

**Don'ts**:
- ❌ 전문 용어 남발
- ❌ 긴 문장
- ❌ 복잡한 레이아웃
- ❌ 과도한 정보

---

### 3. 신뢰성 (Trustworthy)

**목표**: 금융 서비스의 전문성과 안정감 전달

**구현 방법**:
- 차분하고 중립적인 색상
- 깔끔하고 정돈된 레이아웃
- 일관된 디자인 언어
- 전문적인 타이포그래피

**Do's**:
- ✅ 블루·그레이 중심 색상
- ✅ 깔끔한 산세리프 폰트
- ✅ 일관된 간격과 정렬
- ✅ 면책 조항 명시

**Don'ts**:
- ❌ 캐주얼하거나 장난스러운 톤
- ❌ 불규칙한 레이아웃
- ❌ 지나치게 화려한 디자인
- ❌ 신뢰도를 떨어뜨리는 표현

---

### 4. 접근성 (Accessible)

**목표**: 모든 연령대와 능력의 사용자가 쉽게 사용

**구현 방법**:
- WCAG AA 준수
- 키보드 네비게이션 지원
- 스크린 리더 호환
- 충분한 색상 대비

**Do's**:
- ✅ 최소 4.5:1 색상 대비
- ✅ 포커스 인디케이터 명확히
- ✅ ARIA 레이블 사용
- ✅ 최소 14px 폰트 크기

**Don'ts**:
- ❌ 색상에만 의존한 정보 전달
- ❌ 작은 터치 영역
- ❌ 복잡한 키보드 네비게이션
- ❌ 자동 재생 콘텐츠

---

## 1.3 디자인 의사결정 기준

모든 디자인 결정은 다음 질문을 통해 검증합니다:

1. **이 요소가 사용자의 약관 읽기를 방해하지 않는가?**
2. **이 요소가 정보를 명확하게 전달하는가?**
3. **이 요소가 서비스의 신뢰성을 높이는가?**
4. **이 요소가 모든 사용자에게 접근 가능한가?**

네 가지 질문 모두에 "예"라고 답할 수 있을 때만 채택합니다.

# 2. 컬러 시스템

## 2.1 색상 철학

**중립적인 블루·그레이 기반 + 최소 포인트 컬러**

금융 서비스의 전문성과 신뢰성을 전달하면서도, 차분하고 편안한 느낌을 주는 블루·그레이 톤을 중심으로 구성합니다. 형광색, 노랑, 빨강 등 강렬한 색상은 절대 사용하지 않습니다.

## 2.2 Primary Colors (주요 색상)

### Primary Blue (주 색상)

```css
--color-primary: #4A5B6C;
--color-primary-rgb: 74, 91, 108;
```

**용도**: 
- 하이라이트된 용어
- 주요 링크
- 활성화된 상태

**특징**: 차분한 회청색으로 눈에 부담을 주지 않으면서도 명확히 인식 가능

---

### Primary Light (연한 주 색상)

```css
--color-primary-light: #E8EBF0;
--color-primary-light-rgb: 232, 235, 240;
```

**용도**: 
- 하이라이트 배경
- 호버 상태 배경
- 카드 배경

**특징**: 매우 연한 블루 그레이로 텍스트 가독성 유지

---

### Primary Dark (진한 주 색상)

```css
--color-primary-dark: #2F3C4A;
--color-primary-dark-rgb: 47, 60, 74;
```

**용도**: 
- 팝업 헤더
- 강조된 텍스트
- 아이콘

**특징**: 깊이감 있는 회청색

---

## 2.3 Neutral Colors (중립 색상)

### Gray Scale

```css
/* Text Colors */
--color-gray-900: #1A1D23;  /* 본문 텍스트 */
--color-gray-700: #4A4F5A;  /* 보조 텍스트 */
--color-gray-500: #8B909A;  /* 비활성화 텍스트 */
--color-gray-300: #D1D4DA;  /* 경계선 */
--color-gray-100: #F5F6F8;  /* 배경 */
--color-white: #FFFFFF;     /* 흰색 배경 */
```

**사용 가이드**:

| 색상 | 대비율 (on White) | 용도 |
|------|------------------|------|
| Gray 900 | 14.5:1 (AAA) | 본문 텍스트, 제목 |
| Gray 700 | 8.5:1 (AAA) | 보조 텍스트, 설명 |
| Gray 500 | 4.2:1 (AA) | 캡션, 비활성화 |
| Gray 300 | 2.1:1 | 경계선, 구분선 |
| Gray 100 | 1.2:1 | 배경, 카드 |

---

## 2.4 Accent Color (강조 색상)

### Accent Teal (차분한 청록)

```css
--color-accent: #5C8A95;
--color-accent-rgb: 92, 138, 149;
```

**용도**: 
- 관련 용어 링크
- 특별한 강조가 필요한 요소
- 아이콘 포인트

**사용 원칙**:
- 전체 화면의 5% 이하로 제한
- 중요한 정보나 액션에만 사용
- 과도한 사용 금지

---

## 2.5 Semantic Colors (의미 색상)

### Success (성공)

```css
--color-success: #6B8E7F;
--color-success-light: #E8F3EE;
```

**용도**: 성공 메시지, 완료 상태

---

### Warning (경고)

```css
--color-warning: #A87E5C;
--color-warning-light: #F5EFE8;
```

**용도**: 주의 메시지, 중요 안내

---

### Error (오류)

```css
--color-error: #9C6B7A;
--color-error-light: #F3E8EC;
```

**용도**: 오류 메시지, 필수 항목

---

### Info (정보)

```css
--color-info: #6B7F9C;
--color-info-light: #E8EDF3;
```

**용도**: 정보 메시지, 팁

---

## 2.6 금지 색상

다음 색상들은 절대 사용하지 않습니다:

❌ **형광색 (Neon Colors)**
```css
/* 금지 */
#00FF00, #FF00FF, #00FFFF, etc.
```

❌ **순수 노랑 (Pure Yellow)**
```css
/* 금지 */
#FFFF00, #FFD700, #FFF000, etc.
```

❌ **선명한 빨강 (Bright Red)**
```css
/* 금지 */
#FF0000, #FF3333, #FF4444, etc.
```

**이유**: 이러한 색상들은 시각적으로 너무 강렬하여 사용자의 집중을 방해하고, '조용한 보조자' 철학에 부합하지 않습니다.

---

## 2.7 색상 사용 예시

### 하이라이트된 용어

```css
.term-highlight {
  color: var(--color-primary);
  background-color: var(--color-primary-light);
  border-bottom: 1px dashed var(--color-primary);
}
```

### 팝업

```css
.popup {
  background-color: var(--color-white);
  border: 1px solid var(--color-gray-300);
  box-shadow: 0 4px 12px rgba(26, 29, 35, 0.12);
}

.popup-header {
  color: var(--color-primary-dark);
  background-color: var(--color-gray-100);
}

.popup-body {
  color: var(--color-gray-900);
}
```

### 관련 용어 링크

```css
.related-term-link {
  color: var(--color-accent);
  text-decoration: none;
}

.related-term-link:hover {
  text-decoration: underline;
}
```

## 2.8 접근성 체크리스트

모든 색상 조합은 다음을 만족해야 합니다:

- [ ] WCAG AA 준수 (최소 4.5:1 대비율)
- [ ] 색맹 사용자 고려 (색상에만 의존하지 않음)
- [ ] 충분한 시각적 차이
- [ ] 테스트 도구로 검증 완료

**권장 도구**:
- WebAIM Contrast Checker
- Stark (Figma Plugin)
- axe DevTools

# 3. 타이포그래피

## 3.1 폰트 패밀리

### 한글 폰트

**Primary**: Pretendard

```css
font-family: 'Pretendard', -apple-system, BlinkMacSystemFont, system-ui, sans-serif;
```

**특징**:
- 가독성이 뛰어난 현대적 산세리프
- 다양한 굵기 지원 (100-900)
- 웹폰트 최적화
- 오픈소스

**Fallback 순서**:
1. Pretendard
2. -apple-system (iOS/macOS)
3. BlinkMacSystemFont (Chrome)
4. system-ui (시스템 기본)
5. sans-serif (일반 고딕)

---

### 영문/숫자 폰트

**Primary**: Inter

```css
font-family: 'Inter', 'Pretendard', -apple-system, sans-serif;
```

**특징**:
- 숫자 가독성 우수
- 탭ular 숫자 지원
- 한글 폰트와 조화
- 웹폰트 최적화

---

## 3.2 폰트 크기 스케일

### 기본 스케일 (Desktop)

```css
/* Display - 페이지 타이틀 */
--font-size-display: 32px;
--line-height-display: 1.2;
--font-weight-display: 700;

/* H1 - 주요 제목 */
--font-size-h1: 24px;
--line-height-h1: 1.3;
--font-weight-h1: 700;

/* H2 - 섹션 제목 */
--font-size-h2: 20px;
--line-height-h2: 1.4;
--font-weight-h2: 600;

/* H3 - 서브 제목 */
--font-size-h3: 18px;
--line-height-h3: 1.4;
--font-weight-h3: 600;

/* Body - 본문 */
--font-size-body: 16px;
--line-height-body: 1.6;
--font-weight-body: 400;

/* Body Small - 보조 본문 */
--font-size-body-sm: 14px;
--line-height-body-sm: 1.6;
--font-weight-body-sm: 400;

/* Caption - 캡션, 주석 */
--font-size-caption: 12px;
--line-height-caption: 1.5;
--font-weight-caption: 400;
```

---

### 모바일 스케일 (< 768px)

```css
/* Display */
--font-size-display-mobile: 24px;

/* H1 */
--font-size-h1-mobile: 20px;

/* H2 */
--font-size-h2-mobile: 18px;

/* H3 */
--font-size-h3-mobile: 16px;

/* Body - 변경 없음 */
--font-size-body-mobile: 16px;

/* Body Small */
--font-size-body-sm-mobile: 14px;

/* Caption - 최소 크기 유지 */
--font-size-caption-mobile: 12px;
```

---

## 3.3 폰트 굵기 (Font Weight)

```css
--font-weight-regular: 400;  /* 본문 */
--font-weight-medium: 500;   /* 강조 */
--font-weight-semibold: 600; /* 서브 제목 */
--font-weight-bold: 700;     /* 제목 */
```

**사용 가이드**:
- Regular (400): 모든 본문 텍스트
- Medium (500): 버튼, 약한 강조
- Semibold (600): H2, H3, 중요한 정보
- Bold (700): H1, Display, 매우 중요한 정보

---

## 3.4 자간 (Letter Spacing)

```css
/* 제목 */
--letter-spacing-tight: -0.02em;  /* Display, H1 */
--letter-spacing-normal: 0;       /* H2, H3, Body */

/* 특수 */
--letter-spacing-wide: 0.05em;    /* 대문자, 버튼 */
```

**사용**: 팝업 내부 섹션, 카드 제목

```css
  font-size: 12px;

  color: var(--color-gray-500);
```


### 링크
```css

}
```

### 에러 메시지

```css
}
```

## 3.7 가독성 가이드라인

### 팝업 위치 계산

팝업은 하이라이트된 용어 위치에 따라 동적으로 배치:

```javascript
// 의사 코드
function calculatePopupPosition(termElement, popupElement) {
  const termRect = termElement.getBoundingClientRect();
  const popupRect = popupElement.getBoundingClientRect();
  
  // 기본: 용어 위쪽에 표시
  let top = termRect.top - popupRect.height - 8;
  let left = termRect.left;
  
  // 위쪽 공간이 부족하면 아래쪽에 표시
  if (top < 0) {
    top = termRect.bottom + 8;
  }
  
  // 오른쪽으로 넘치면 조정
  if (left + popupRect.width > window.innerWidth) {
    left = window.innerWidth - popupRect.width - 16;
  }
  
  return { top, left };
}
```

# 6. 애니메이션 및 트랜지션

## 6.1 애니메이션 원칙

### 목적
- 사용자에게 피드백 제공
- 상태 변화를 부드럽게 표현
- 공간적 관계 이해 돕기
- **절대 주의를 빼앗지 않기**

### 속도
- **빠르고 부드럽게**: 0.2s - 0.3s
- 사용자를 기다리게 하지 않음
- 하지만 갑작스럽지 않게

---

## 6.2 트랜지션 타이밍

```css
/* Fast - 즉각적 피드백 */
--transition-fast: 0.15s;

/* Base - 기본 트랜지션 */
--transition-base: 0.25s;

/* Slow - 부드러운 등장/퇴장 */
--transition-slow: 0.3s;
```

```css
--ease-out: cubic-bezier(0.0, 0.0, 0.2, 1);

--ease-in: cubic-bezier(0.4, 0.0, 1, 1);
```

### Tab 순서

모든 인터랙티브 요소는 논리적 순서로 탭 접근 가능:
